## 🎨 Project Overview

This project is a **stylized low-poly neighborhood scene** created in Blender.

The scene includes multiple houses, windows, doors, trees, fences, roads, and environmental elements arranged to create a small residential neighborhood.

## 🛠️ Tools & Technologies

- **Blender**
- 3D Modeling
- Low-Poly Modeling
- Materials & Shading
- Lighting
- Camera Composition
- Rendering

## ✨ Key Features

- Stylized low-poly houses
- Detailed windows and doors
- Trees and greenery
- Fences and pathways
- Repeated building structures
- Custom materials and colors
- Environmental composition
- Camera setup and rendering
